## 第一部分：什么是 HRV——彻底讲透

### 1.1 一个类比理解 HRV

你的心跳并不是像钟表一样规律跳动。如果你的心跳永远是"咚—咚—咚—咚"，每次间隔精确 1.00 秒，那反而说明你的身体出了问题。

**HRV 描述的是这个现象：连续两次心跳之间的时间间隔并不相等，它们在微妙地变化。**

**类比 1：汽车发动机**
- 想象你在等红灯。汽车发动机闲置时，转速不是固定的，而是在一个范围内微妙波动。这种"微调"越灵活，发动机越健康。
- 如果转速变成"死开关"（要么转要么停），说明发动机有问题。
- 你的心脏也是这样：**HRV 高 = 自主神经调节灵活 = 健康**。

**类比 2：音乐节奏**
- 健康的心跳像一首流畅的钢琴曲，有快有慢，有强有弱。
- 不健康的心跳像一台机器人在打点子鼓——绝对规律，绝对死板。

**类比 3：車流量**
- 高峰期的高速公路：车辆时而加速、时而减速，整体流动顺畅。这是高 HRV。
- 严重堵车：每辆车都以同一个速度跟车。这是低 HRV。

### 1.2 为什么心跳会"不规律"

你的心脏有两套"操控系统"：

```
        大脑
         |
    自主神经系统 (ANS)
      /        \
  交感神经      副交感神经
   (SNS)         (PNS)
   “加油”        “刹车”
     |              |
  心率加快      心率减缓
  心肌收缩      心肌放松
     |              |
    HRV下降       HRV升高
```

**交感神经 (SNS) —— “加油模式"”**
- 作用：加快心率、收缩血管、提高血压
- 实际场景：被老板骂了、快迟到了、马路上有人刮了你的车
- 对 HRV 的影响：**减少 HRV**（心跳变得更规律，因为 SNS 在"统一指挥"）

**副交感神经 (PNS) —— “休息模式"”**
- 作用：减缓心率、促进消化、修复组织
- 实际场景：睡前放松、深呼吸、睡眠中
- 对 HRV 的影响：**增加 HRV**（心跳变得更不规律，因为 PNS 在"灵活调节"）

**关键认知：HRV 不是某一个神经的"单独表现"，而是两套系统"对抗/协作"的结果。**

- 高 HRV = 两套系统都健康，可以快速切换
- 低 HRV = 其中一套系统过度激活（通常是 SNS），导致失去灵活性

### 1.3 从原始信号到 HRV 数值

**步骤 1：获取心跳时间**

从心电图 (ECG) 或光传感感测量 (PPG) 中，检测每一次心跳的时刻点。

- ECG 的 R 波：心电图上最高的尖峰
- PPG 的波峰：血流量达到峰值的时刻

**步骤 2：计算 RR 间期**

连续两个 R 波（或 PPG 波峰）之间的时间间隔。

```
心跳序列：   *     *      *    *       *     *
时间：     0s   0.9s   1.8s  2.5s   3.3s  4.2s
RR 间期：      0.9s   0.9s  0.7s   0.8s   0.9s
心率 (BPM)：   67    67    86    75     67
```

**步骤 3：分析 RR 间期的"变化程度"→ 这就是 HRV**

如果上面的 RR 间期全部是 0.9s，HRV = 0（完全没有变化）
如果上面的 RR 间期是 0.9s、0.7s、0.8s、1.0s、0.6s，HRV 很高

### 1.4 HRV 和心率的区别

| 维度 | 心率 (Heart Rate) | HRV (Heart Rate Variability) |
|------|------------------|-----------------------------|
| 定义 | 每分钟心跳次数 | 心跳间隔的变化程度 |
| 单位 | BPM (次/分钟) | 毫秒 (ms) 或毫秒的标准差 |
| 反映 | 当前心脏负荷 | 自主神经系统健康度 |
| 例子 | 60 BPM vs 80 BPM | 同为 60 BPM 时，HRV 可能差很大 |

**关键认知**：两个人心率都是 60 BPM，但一个人的 HRV 是 100ms，另一个是 20ms。第二个人的自主神经系统健康度更差，即使心率相同。

### 1.5 HRV 的主要应用场景

| 场景 | HRV 变化特征 | 实际应用 |
|------|------------|---------|
| **压力/焦虑** | HRV 下降，特别是 RMSSD 和 HF 下降 | 实时压力监测、燃尽预警 |
| **运动恢复** | 运动中 HRV 下降，恢复中 HRV 回升 | 过度训练检测、训练强度推荐 |
| **睡眠质量** | 深睡期间 HRV 升高，睡眠不足时次日 HRV 下降 | 睡眠障碍筛查、睡眠 coaching |
| **情绪状态** | 情绪波动与 HRV 波动强相关 | 情绪 Agent 触发器 |
| **生物年龄** | HRV 随年龄下降 | 健康老化评估 |

## 第二部分：HRV 计算方法详解

### 2.1 整体流程

```
原始信号 (ECG/PPG)
    ↓
[滤波去噪]
    ↓
[波峰检测] → 得到每次心跳的时刻 t1, t2, t3...
    ↓
[计算 RR 间期] → RR[i] = t(i+1) - t(i)
    ↓
[异常值过滤] → 移除错误检测
    ↓
[指标计算] → 时域 / 频域 / 非线性
```

### 2.2 滤波去噪 (Signal Preprocessing)

**目的**：移除基线漂移、肌电干扰、电源干扰等。

**常用方法**：

| 方法 | 适用场景 | 说明 |
|------|---------|------|
| **带通滤波器** (Bandpass Filter, 0.5-40Hz) | ECG | 保留心电信号主频率，去除低频基线和高频噪声 |
| **中值滤波器** (Median Filter) | ECG/PPG | 去除脉冲式噪声 |
| **平滑滤波** (Savitzky-Golay) | PPG | 保持峰形的同时平滑曲线 |
| **小波去噪** (Wavelet Denoising) | ECG/PPG | 适合非平稳信号 |

**代码示例**（Python + SciPy）：
```python
from scipy.signal import butter, filtfilt

# Butterworth 带通滤波器
lowcut, highcut = 0.5, 40.0  # Hz
nyq = 0.5 * fs  # fs 为采样率
low = lowcut / nyq
high = highcut / nyq
b, a = butter(4, [low, high], btype='band')
filtered_signal = filtfilt(b, a, raw_signal)
```

### 2.3 波峰检测 (Peak Detection)

**目的**：准确找到每一次心跳的位置。

**常用方法**：

#### 方法 A：动态阈值 + 最小间距约束

```
波峰检测算法：
1. 设置动态阈值 = 信号均值 + 系数 × 标准差
2. 当信号超过阈值时，记录一个候选峰
3. 确保上一个峰与当前峰的间距 > 最小间距（如 300ms，对应最大心率 200 BPM）
4. 如果在搜索窗口内有多个超过阈值的点，只保留最大值
```

#### 方法 B：Pan-Tompkins 算法（ECG 金标准）

```
Pan-Tompkins 算法步骤：
1. 带通滤波 (5-15 Hz) → 保留 QRS 复合波
2. 微分 → 突出斜率变化
3. 平方 → 强化高频成分
4. 移动窗口积分 → 平滑
5. 阈值检测 → 定位 R 波
6. 回望搜索 → 精细校准
```

**代码示例**（使用 scipy.signal.find_peaks）：
```python
from scipy.signal import find_peaks

# 对滤波后的信号检测波峰
peaks, properties = find_peaks(
    filtered_signal,
    distance=min_distance_samples,  # 最小间距，如 fs*0.3
    prominence=prominence_threshold  # 突出度阈值
)
```

#### 方法 C：PPG 波峰检测

```
PPG 波峰检测的特殊处理：
1. PPG 信号有重搏波 (dicrotic wave)，需要识别主波
2. 使用一阶导数辅助确定主波位置
3. 常用算法：自相关性 + 动态阈值
```

### 2.4 异常值过滤 (Artifact Removal)

**为什么需要**：PPG 运动伪迹、检测丢失等会导致错误的 RR 间期。

**过滤规则**：

| 类型 | 条件 | 处理 |
|------|------|------|
| **短 RR** | RR < 300ms (心率 > 200 BPM) | 删除或标记 |
| **长 RR** | RR > 2000ms (心率 < 30 BPM) | 删除或标记 |
| **RR 变化过大** | |ΔRR| > 200ms | 删除或标记 |
| **运动伪迹** | 加速度计读数 > 阈值 | 屏蔽该区间 |

**代码示例**：
```python
rr_intervals = np.diff(peaks) / fs * 1000  # 转换为毫秒

# 过滤异常值
valid_mask = (rr_intervals > 300) & (rr_intervals < 2000)
# 过滤 RR 变化过大
valid_mask &= np.abs(np.diff(rr_intervals, prepend=rr_intervals[0])) < 200

rr_clean = rr_intervals[valid_mask]
```

### 2.5 时域分析 (Time Domain)

**核心思想**：直接统计 RR 间期的数字特征。

#### SDNN —— 标准差

**定义**：所有正常 RR 间期的标准差。

```
SDNN = sqrt( mean( (RR[i] - mean(RR))^2 ) )
```

**含义**：反映 HRV 的整体水平。值越大，心率变化越大。

**参考范围**：
- 青年人：55-105 ms
- 中年人：35-75 ms
- 老年人：20-45 ms

**代码**：
```python
sdnn = np.std(rr_intervals, ddof=1)
```

#### RMSSD —— 相邻差值均方根

**定义**：相邻两个 RR 间期差值的平方和的平方根。

```
RMSSD = sqrt( mean( (RR[i+1] - RR[i])^2 ) )
```

**含义**：主要反映短期 HRV，与副交感神经 (PNS) 活性强相关。

**为什么它重要**：
- 对压力、情绪变化非常敏感
- 计算简单，适合实时应用
- 是 Apple Watch 等消费级设备的主要 HRV 指标

**代码**：
```python
rmssd = np.sqrt(np.mean(np.diff(rr_intervals)**2))
```

#### pNN50 —— 大于 50ms 的百分比

**定义**：相邻 RR 间期差值超过 50ms 的百分比。

```
pNN50 = count(|RR[i+1] - RR[i]| > 50ms) / total_count * 100%
```

**含义**：反映心率的"突然变化"程度，与 PNS 活性强相关。

**代码**：
```python
nn50 = np.sum(np.abs(np.diff(rr_intervals)) > 50)
pnn50 = 100.0 * nn50 / len(np.diff(rr_intervals))
```

### 2.6 频域分析 (Frequency Domain)

**核心思想**：将 RR 间期序列看作一个"信号波"，通过傅里叶变换 (FFT) 分解为不同频率的成分。

**为什么可以这么做**：
- 交感神经 (SNS) 的活动在较低频率（<0.15Hz）
- 副交感神经 (PNS) 的活动在较高频率（>0.15Hz，与呼吸同步）
- 通过分析频率分布，可以尝试区分两套系统的贡献

**实施步骤**：

```
步骤 1：拒绝 RR 间期序列
步骤 2：插值为均匀采样率信号（通常使用 cubic spline 插值）
步骤 3：移除趋势 (去除平均值)
步骤 4：加窗（通常使用 Hanning 窗或 Welch 方法）
步骤 5：FFT 变换
步骤 6：计算各频率带的功率
```

**频率带**：

| 带 | 频率范围 | 主要反是 |
|-----|--------|----------|
| VLF | < 0.003 Hz | 温度调节、神经内分泌（不确定） |
| LF | 0.003-0.15 Hz | SNS + PNS 混合 |
| HF | 0.15-0.4 Hz | PNS 主导（呼吸同步） |

**关键指标**：
- **LF/HF 比值**：强调的平衡指标。高值表示 SNS 优势（压力、焦虑）。
- 但存在争议：LF 并非纯 SNS 指标，应小心解读。

**代码示例**：
```python
from scipy.interpolate import CubicSpline
from scipy.fft import fft
from scipy.signal import welch

# 插值
rr_times = np.cumsum(rr_intervals) / 1000.0  # 秒
fs_interp = 4.0  # Hz
t_interp = np.arange(rr_times[0], rr_times[-1], 1.0/fs_interp)
cs = CubicSpline(rr_times, rr_intervals)
rr_interp = cs(t_interp)

# 去趋势
rr_detrended = rr_interp - np.mean(rr_interp)

# Welch 方法计算功率谱
f, psd = welch(rr_detrended, fs=fs_interp, nperseg=256)

# 计算 HF 和 LF
hf_power = np.trapz(psd[(f >= 0.15) & (f <= 0.4)], f[(f >= 0.15) & (f <= 0.4)])
lf_power = np.trapz(psd[(f >= 0.04) & (f <= 0.15)], f[(f >= 0.04) & (f <= 0.15)])
lf_hf_ratio = lf_power / hf_power
```

### 2.7 非线性分析 (Nonlinear Analysis)

**核心思想**：心率变化不是简单的线性波动，而是复杂的动态系统。非线性方法能捕捉到线性方法看不到的特征。

#### Poincaré 散点图

**原理**：将相邻的 RR 间期绘制成二维座标。

```
横轴：RR[i]   纵轴：RR[i+1]

散点分布形状解读：
- 圆形/椭圆形 = 正常
- 拙圆形（横轴长） = 长期变化多
- 拙圆形（纵轴长） = 短期变化多
```

**从圆中推导出 SD1 和 SD2**：
- SD1：散点图沿对角线方向的标准差 → 反映短期 HRV
- SD2：散点图垂直于对角线方向的标准差 → 反映长期 HRV

```python
rr_n = rr_intervals[:-1]
rr_n1 = rr_intervals[1:]

# SD1 和 SD2
sd1 = np.std(rr_n1 - rr_n) / np.sqrt(2)
sd2 = np.std(rr_n1 + rr_n) / np.sqrt(2)
```

#### 浅度散度 (Approximate Entropy / Sample Entropy)

**原理**：量化 RR 序列的"不可预测性"。

```
高熵 = 心率变化复杂、不可预测 = 健康
低熵 = 心率变化简单、可预测 = 不健康
```

**意义**：健康的心脏具有"健康的混沌"——它不是机械的、可预测的。

#### 去趋波动分析 (DFA)

**原理**：检测 RR 序列中的"长期相关性"——即今天的 HRV 与明天的 HRV 之间是否存在统计关联。

**关键指标**：
- α1（短期，4-11 个心跳）：短期相关性
- α2（长期，>11 个心跳）：长期相关性

### 2.8 方法选择指南

| 应用场景 | 推荐方法 | 理由 |
|---------|---------|------|
| 实时压力监测 | RMSSD | 计算快、对 PNS 敏感、可实时 |
| 睡眠分析 | 夜间 SDNN + 频域分析 | 可区分睡眠阶段 |
| 运动恢复 | SDNN + RMSSD | 全面评估 |
| 情绪检测 | RMSSD + LF/HF | 综合两系统 |
| 病理诊断 | 时域 + 频域 + 非线性 | 多角度评估 |
| 端侧实时 | 仅 RMSSD + 简化波峰检测 | 计算量小 |

### 3.1 Python 核心工具库

#### 1. NeuroKit2 ⭐ 2237

**链接**：https://github.com/neuropsychology/NeuroKit

**简介**：神经生理信号处理的 Python 全栈工具箱，支持 ECG、EDA、EEG、EMG、RSP 等多种生理信号。

**和 HRV 相关的功能**：
- 完整的 HRV 分析（时域、频域、非线性）
- ECG 信号预处理和 R 波检测
- PPG 信号处理
- 内置多种可视化
- 支持与 pandas DataFrame 无缝集成

**使用示例**：
```python
import neurokit2 as nk

# 模拟 ECG 信号
ecg_signal = nk.ecg_simulate(duration=60, sampling_rate=1000)

# 预处理
cleaned_ecg = nk.ecg_clean(ecg_signal, sampling_rate=1000)

# R 波检测
peaks, info = nk.ecg_peaks(cleaned_ecg, sampling_rate=1000)

# HRV 分析
hrv = nk.hrv(peaks, sampling_rate=1000, show=True)

# hrv 是一个 DataFrame，包含所有时域、频域、非线性指标
```

**优势**：
- 功能最全面，一站式解决方案
- 文档极佳，教程丰富
- 社区活跃，更新频繁
- 支持多种信号的多模态分析

**劣势**：
- 功能过多可能导致上手学习曲线较长
- 部分高级功能依赖其他库

**推荐程度**：⭐⭐⭐⭐⭐ —— 首选工具

#### 4. OpenHRV ⭐ 171

**链接**：https://github.com/JanCBrammer/OpenHRV

**使用场景**：

### HRV 指标快速查表

| 指标 | 英文全称 | 计算 | 主要反是 |
|------|---------|------|----------|
| SDNN | Standard Deviation of NN intervals | RR 标准差 | 整体 HRV |
| RMSSD | Root Mean Square of Successive Differences | 相邻差值均方根 | 短期 HRV / PNS |
| pNN50 | Percentage of NN50 | >50ms 差值百分比 | PNS 活性 |
| LF | Low Frequency | 0.04-0.15 Hz 功率 | SNS+PNS 混合 |
| HF | High Frequency | 0.15-0.4 Hz 功率 | PNS /呼吸 |
| LF/HF | LF to HF ratio | LF/HF | 神经平衡 |
| SD1 | Poincaré plot short axis | 散点图短轴 | 短期 HRV |
| SD2 | Poincaré plot long axis | 散点图长轴 | 长期 HRV |

> 
> HRV 的本质是"心脏的灵活性"。学会计算 HRV 很容易，难的是理解它背后的生理学意义，并用它构建有价值的产品。

> 当前最大的机会不在于"如何计算 HRV"，而在于"如何用 HRV 做出有意义的事情"。
