## 概述：rPPG 与 HRV

### 什么是 rPPG

rPPG (remote Photoplethysmography) 是一种**非接触式的心率检测技术**。它通过普通摄像头捕捉人脸部皮肤颜色的微妙变化，推断出血流量的周期性波动，从而得到脉率信号。

```
光源 (自然光/人工光)
    ↓
脸部皮肤吸收 & 反射
    ↓
摄像头传感器 (RGB)
    ↓
颜色变化分析 (通常用绿色通道 G)
    ↓
脉率信号 (Pulse Wave) → 心率 (HR) → HRV
```

### rPPG 抽取 HRV 的挑战

| 挑战 | 影响 | 程度 |
|------|------|------|
| **采样率限制** | 传统摄像头 30fps 意味着时间分辨率仅 33ms | ⭐⭐⭐⭐ |
| **运动伪迹** | 头部/面部运动导致 ROI 飘移 | ⭐⭐⭐⭐⭐ |
| **光照变化** | 环境光线强度/颜色温度改变 | ⭐⭐⭐⭐ |
| **肤色差异** | 深色皮肤吸光特性不同 | ⭐⭐⭐ |
| **信号噪声** | rPPG 信号信噪比低于接触式 PPG | ⭐⭐⭐⭐ |
| **帧同步** | 视频编码/传输引入的时间洪流 | ⭐⭐⭐ |

**关键认知**：
- rPPG 可以推估 HR，但推估 HRV 的难度大幅提升
- 当前 SOTA rPPG 方法在静止状态下的 HR 误差约 1-3 BPM
- 但 rPPG 推导的 HRV 指标（如 RMSSD）与接触式 PPG/ECG 的相关性仅为 0.5-0.7
- **高帧率摄像头（60fps+）是提高 rPPG-HRV 精度的关键**

#### 1. MAHNOB-HCI ⭐⭐⭐⭐⭐

**基本信息**
- 来源：Imperial College London / University of Twente, 2012
- 被试：27 人
- 视频：近眼 (EyeTap) + 远眼 (Scene camera)
- 分辨率：780×580 (Scene), 更高分辨率的面部区域
- 帧率：61 fps
- 时长：因视频而异，通常 1-3 分钟

**生理信号 Ground Truth**
- ECG (3-lead, 256 Hz)
- GSR/EDA (256 Hz)
- EEG (32 channels, 256 Hz)
- 呼吸带 (Respiration belt)
- 体温 (Skin temperature)

**惇绪标注**
- 观看情感视频后自评 Valence/Arousal/Dominance
- 外部观察者评估
- 20 种惇绪标签

**下载**
- https://mahnob-db.eu/hci-tagging/
- 需要注册并签署使用协议

**适合 HRV 的理由**
- ECG ground truth 质量高，可可靠地计算 HRV
- 有同步的面部视频，可用于 rPPG 算法训练与验证
- 惇绪标注丰富，可构建 HRV-惇绪映射

## HRV 分析可行性评估

### rPPG 提取 HRV 的目前水平

**从 rPPG 到 HRV 的流程**：
```
视频
  ↓ 面部检测 + ROI 追踪
  ↓ 颜色变化提取 (通常用绿色通道)
  ↓ 去趋势 + 滤波
  ↓ 脉率波形 (Pulse Wave)
  ↓ 波峰检测
  ↓ 计算脉率 (HR)
  ↓ 计算 HRV (需要高精度的脉率序列)
```

**关键约束**：
- 正常视频 30fps 意味着两帧之间间隔 33.3ms
- 人的心率通常 60-100 BPM，即 RR 间期 600-1000ms
- 但 HRV 的变化通常只有 20-100ms
- **30fps 下的时间分辨率 (33ms) 已经接近 HRV 变化的量级**

**常用方法**：
1. **插值法**：在检测到的脉率峰值之间做 spline 插值，提高时间分辨率
2. **相位分析**：利用脉率波形的相位信息，而不是只用峰值
3. **机器学习直接回归**：训练端到端的 rPPG → HRV 映射

```
    |       ├—— 需要丰富的惇绪标注 → MAHNOB-HCI / DEAP / ReMOTION
    |       |
    |       └—— 需要压力激发 → UBFC-Phys / WESAD
    |
    ├—— rPPG 算法验证
    |       |
    |       ├—— 静止场景 → UBFC-rPPG / PURE / COHFACE
    |       |
    |       └—— 运动/复杂场景 → MMPD / MR-NIRP / VIPL-HR
    |
    ├—— 长期 HRV 监测
    |       |
    |       └—— → FusionVitals (唯一选择)
    |
    ├—— 运动场景

    |
    └—— 驾驶/工业安全
            |
            └—— → ORPDAD / WESAD
```

## 关键结论

1. **最适合 HRV 惇感计算的 rPPG 数据集**：ReMOTION, MAHNOB-HCI, DEAP, WESAD, UBFC-Phys

2. **最适合算法开发的数据集**：UBFC-rPPG, VIPL-HR, PURE

3. **唯一长期监测数据集**：FusionVitals

4. **最大规模合成数据集**：SCAMPS (3600 人)

5. **rPPG-HRV 的核心挑战**：
   - 帧率限制（30fps 时间分辨率不足）
   - 运动伪迹
   - 信号噪声
   - 个体差异性

6. **推荐的组合策略**：
   - 在有 ECG/PPG ground truth 的数据集上训练 rPPG 提取器
   - 在有惇绪标注的数据集上训练 HRV → 惇绪映射模型
   - 使用 SCAMPS 进行预训练
   - 最终在无标签视频上做无监督学习
