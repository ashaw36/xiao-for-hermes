## 第一部分：科研现状

### 1.1 为什么用 HRV 做情感计算

**核心逻辑**：情绪不是"纯心理现象"，而是"生理心理一体现象"。当你感到焦虑时，你的身体比你的意识更早知道。

```
外界刺激
    ↓
大脑边缘系统（下丘脑、脑干）
    ↓
自主神经系统 (ANS)
    /        \
交感神经(SNS)     副交感神经(PNS)
  “战逃反应”        “休息消化”
    ↓              ↓
 心率加快         心率减缓
 HRV下降         HRV升高
    ↓              ↓
  可以用电极/光传感感测量 → 推断情绪状态
```

**相比其他生理信号的优势**：

| 信号 | 优势 | 劣势 | 情感关联强度 |
|------|------|------|------------|
| **HRV/ECG** | 可穿戴、长时间连续监测、难伪造 | 个体差异大、受运动影响 | ⭐⭐⭐⭐ |
| **EDA/GSR** | 对情绪敏感、响应快 | 容易受温度/湿度影响 | ⭐⭐⭐⭐ |
| **EEG** | 直接测量大脑活动 | 需要多电极、不适合日常穿戴 | ⭐⭐⭐⭐⭐ |
| **面部表情** | 直观、非接触 | 容易伪装、光线依赖 | ⭐⭐⭐ |
| **语音** | 自然交互 | 受文化/语言影响 | ⭐⭐⭐ |

**关键认知**：HRV 不是情绪的"指纹"，而是"监测器"。它可以告诉你"身体正在反应"，但无法单独告诉你"这是哪种情绪"。这是 HRV 情感计算的核心局限。

### 1.2 情感模型：如何定义和标注情绪

**离散模型 (Discrete Model)**
- 将情绪分为固定类别：喜、怒、哀、恐、厌等
- 问题：生理学上难以区分"怒怒"和"兴奋"，因为两者都激活 SNS
- 在 HRV 研究中已渐渐被放弃

**维度模型 (Dimensional Model) —— 当前主流**
- 以 Russell 的环形模型 (Circumplex Model) 为基础
- 用三个维度定义任何情绪：

```
        高催化 (High Arousal)
              |
    兴奋      |      焦虑
              |
低价值 ———————————————— 高价值 (Valence)
              |
    忧郇      |      冷静
              |
        低催化 (Low Arousal)

第三维度：Dominance (支配度) —— 感觉对情境的控制程度
```

| 情绪 | 价值 (Valence) | 催化 (Arousal) | 支配 (Dominance) |
|------|---------------|---------------|-----------------|
| 开心 | 高 | 中高 | 中 |
| 惊恐 | 低 | 高 | 低 |
| 愤怒 | 低 | 高 | 高 |
| 悲伤 | 低 | 低 | 低 |
| 放松 | 高 | 低 | 中 |

**对 HRV 的意义**：
- **Valence** 与 HRV 的关联较弱（但高价值通常对应更高 HRV）
- **Arousal** 与 HRV 关联强：高催化 → SNS 优势 → HRV 下降
- **Dominance** 通常需要结合其他信号判断

**标注方式**：
- **Self-report**：观看影片后在 SAM 量表 (Self-Assessment Manikin) 上打分
- **Continuous annotation**：观看过程中实时拖动滑块标注 valence/arousal
- **Stimulus-based**：假设所有人对同一影片产生同样情绪（强劣势）

### 1.3 核心数据集详解

数据集是 HRV 情感计算的"基座设施"。以下是所有重要数据集的全景对比。

#### DEAP (Dataset for Emotion Analysis using EEG, Physiological and Video Signals)

**基本信息**：
- 来源：Queen Mary University of London, 2012
- 被试：32 人（19-37 岁，50%女性）
- 影片：40 段 1 分钟音乐视频
- 采样率：512 Hz (EEG), 128 Hz (GSR, 体温, 呼吸, 血氧）, 128 Hz (ECG)
- 情绪维度：Valence, Arousal, Dominance, Liking
- 标注：观看影片后使用 1-9 分量表自评

**数据结构**：
```
每个被试者：40 个 trial
每个 trial：
  - 3s 基线 (baseline)
  - 60s 视频
  - 自评 (valence, arousal, dominance, liking, 是否熟悉)
  - 生理信号 (EEG 32通道 + ECG + GSR + 体温 + 呼吸 + 血氧)
```

**在 HRV 情感计算中的使用**：
- ECG 信号可提取 RR 间期，计算 HRV 特征
- 最常用于二分类任务：高/低 Valence，高/低 Arousal
- 问题：视频长度仅 1 分钟，HRV 分析窗口较短
- 下载：http://www.eecs.qmul.ac.uk/mmv/datasets/deap/

#### DREAMER

**基本信息**：
- 来源：University of the West of Scotland, 2017
- 被试：23 人（18-33 岁）
- 影片：18 段电影片段
- 采样率：256 Hz (EEG), 256 Hz (ECG)
- 情绪维度：Valence, Arousal, Dominance
- 标注：1-5 分量表

**特点**：
- 相比 DEAP 更精简，更适合快速验证
- ECG 采样率较高，适合 HRV 分析
- 被试人数较少，个体差异性结果不稳定
- 下载：https://zenodo.org/record/546113

#### WESAD (Wearable Stress and Affect Detection)

**基本信息**：
- 来源：Universität Duisburg-Essen, 2018
- 被试：15 人（12 男 3 女）
- 条件：三种实验条件（中性、压力、娱乐）
- 采样率：700 Hz (RespiBAN Pro)
- 信号：ECG, EDA, 温度, 呼吸, EMG, 加速度计
- 标注：客观生理状态标签（不是主观情绪打分）

**特点**：
- 专为可穿戴设备设计
- 包含压力和娱乐两种情感状态
- 采样率极高，适合细粒度分析
- 适合三分类（中性/压力/娱乐）
- 下载：https://archive.ics.uci.edu/ml/datasets/WESAD

#### AMIGOS (A Dataset for Affect, Personality and Mood Research on Individuals and Groups)

**基本信息**：
- 来源：Northeastern University, 2018
- 被试：40 人
- 影片：16 段短视频（短于 2 分钟） + 4 段长视频（长于 14 分钟）
- 采样率：128 Hz (EEG), 128 Hz (ECG), 128 Hz (EDA)
- 惇绪维度：Valence, Arousal, Dominance
- 标注：自评 + 外部观察者评估

**特点**：
- 包含短视频和长视频，适合时间序列模型
- 有外部观察者标注，可以分析自我报告与外部观察的一致性
- 下载：https://www.eecs.qmul.ac.uk/mmv/datasets/amigos/

#### SWELL (Stress in Work and Everyday Life)

**基本信息**：
- 来源：Delft University of Technology, 2014
- 被试：25 人（知识工作者）
- 任务：在压力和非压力条件下完成知识工作任务
- 信号：ECG, EDA, 面部表情、姿态、键盘/鼠标行为
- 采样率：2048 Hz (ECG)

**特点**：
- 专注于工作压力，具有极高实际应用价值
- 包含行为数据，可分析生理-行为联动
- 下载：http://cs.ru.nl/~swell/

#### CASE (Complex Activity-based Stress Detection)

**基本信息**：
- 来源：University of Oulu, 2019
- 被试：30 人
- 场景：计算机使用任务
- 信号：ECG, EDA, 呼吸, 面部表情

**特点**：
- 专注于计算机使用情境下的压力
- 适合办公室/工作场景应用

#### 其他重要数据集

| 数据集 | 被试 | 情绪/状态 | 生理信号 | 特点 |
|------|------|-----------|---------|------|
| **RECOLA** | 46 人 | 情绪连续标注 | ECG, EDA, EEG, 面部, 语音 | 远程协作 |
| **AVEC** | 变化 | 抑郁症严重程度 | ECG, 语音, 面部 | 年度挑战赛 |
| **Ascertain** | 55 人 | 情绪类别 | EEG, ECG, GSR, 面部 | 视频觢放 |
| **MPED** | 23 人 | 情绪类别 | EEG, ECG, GSR, 面部 | 中文影片 |
| **OMGE** | 40 人 | 情绪类别 | ECG, EDA | 多生理信号 |

### 1.4 特征工程详解

HRV 情感计算的特征工程有两条路：**handcrafted features** 和 **learned features**。

#### 方法 A：Handcrafted Features (传统方法)

从 RR 间期串中手工提取统计特征，然后输入分类器。

**时域特征**：
```python
features = {
    # 统计量
    'mean_rr': np.mean(rr_intervals),
    'std_rr': np.std(rr_intervals),           # = SDNN
    'rmssd': np.sqrt(np.mean(np.diff(rr_intervals)**2)),
    'pnn50': 100 * np.sum(np.abs(np.diff(rr_intervals)) > 50) / len(np.diff(rr_intervals)),
    'pnn20': 100 * np.sum(np.abs(np.diff(rr_intervals)) > 20) / len(np.diff(rr_intervals)),
    
    # 极值
    'max_rr': np.max(rr_intervals),
    'min_rr': np.min(rr_intervals),
    'range_rr': np.max(rr_intervals) - np.min(rr_intervals),
    
    # 高阶矩
    'skewness': scipy.stats.skew(rr_intervals),
    'kurtosis': scipy.stats.kurtosis(rr_intervals),
}
```

**频域特征**：
```python
# 需要先对 RR 间期插值为均匀采样信号
from scipy.interpolate import CubicSpline
from scipy.signal import welch

rr_times = np.cumsum(rr_intervals) / 1000.0  # 秒
t_interp = np.arange(rr_times[0], rr_times[-1], 1/4.0)
cs = CubicSpline(rr_times, rr_intervals)
rr_interp = cs(t_interp)

f, psd = welch(rr_interp - np.mean(rr_interp), fs=4.0, nperseg=256)

freq_features = {
    'lf_power': np.trapz(psd[(f>=0.04)&(f<0.15)], f[(f>=0.04)&(f<0.15)]),
    'hf_power': np.trapz(psd[(f>=0.15)&(f<=0.4)], f[(f>=0.15)&(f<=0.4)]),
    'lf_hf_ratio': lf_power / hf_power,
    'lf_norm': lf_power / (lf_power + hf_power),
    'hf_norm': hf_power / (lf_power + hf_power),
}
```

**非线性特征**：
```python
# Poincaré plot
sd1 = np.std(np.diff(rr_intervals)) / np.sqrt(2)
sd2 = np.std(rr_intervals[:-1] + rr_intervals[1:]) / np.sqrt(2)

# 浅度散度 (Approximate Entropy)
def approximate_entropy(U, m, r):
    def _phi(m):
        x = np.array([U[i:i+m] for i in range(len(U)-m+1)])
        C = np.sum(np.max(np.abs(x[:, None] - x[None, :]), axis=2) <= r, axis=0) / (len(U)-m+1)
        return np.sum(np.log(C)) / (len(U)-m+1)
    return _phi(m) - _phi(m+1)

apen = approximate_entropy(rr_intervals, m=2, r=0.2*np.std(rr_intervals))
```

**常用特征集合**：
- 时域：15-20 个特征
- 频域：5-10 个特征
- 非线性：5-10 个特征
- **总共通常 30-50 个 handcrafted features**

#### 方法 B：Learned Features (深度学习)

用神经网络直接从 raw RR 间期或 raw ECG/PPG 中学习特征。

**1D-CNN 路径**：
```
Raw ECG (1D signal)
    ↓ Conv1D(64, kernel=3) + ReLU + MaxPool
    ↓ Conv1D(128, kernel=3) + ReLU + MaxPool
    ↓ Conv1D(256, kernel=3) + ReLU + GlobalAvgPool
    ↓ Dense(64) + Dropout
    ↓ Dense(num_classes, softmax)
```

**LSTM 路径**：
```
RR intervals (time series)
    ↓ LSTM(64, return_sequences=True)
    ↓ LSTM(32)
    ↓ Dense(16)
    ↓ Dense(num_classes, softmax)
```

**Transformer 路径 (TACOformer 等)**：
```
Raw signal patches
    ↓ Patch Embedding
    ↓ Positional Encoding
    ↓ Multi-Head Self-Attention × N
    ↓ Global Average Pooling
    ↓ Dense(num_classes)
```

### 1.5 传统机器学习方法与准确率

**方法**：SVM, k-NN, Random Forest, XGBoost, Logistic Regression

**典型实验设置**：
- 特征：30-50 个 handcrafted HRV 特征
- 分类：二分类（高/低 Valence 或 Arousal）
- 评估：Leave-One-Subject-Out (LOSO) 或 Train/Test Split

**准确率汇总**（Subject-Independent, LOSO 验证）：

| 数据集 | 任务 | SVM | RF | k-NN | XGBoost | 最佳方法 |
|------|------|-----|----|------|---------|---------|
| **DEAP** | 高/低 Valence | 62.5% | 64.2% | 58.3% | 65.8% | 68.1% (RF+特征选择) |
| **DEAP** | 高/低 Arousal | 68.3% | 70.1% | 65.4% | 71.2% | 73.5% (SVM+RBF) |
| **DREAMER** | 高/低 Valence | 55.2% | 58.1% | 52.3% | 59.4% | 61.0% (SVM) |
| **DREAMER** | 高/低 Arousal | 62.8% | 65.3% | 60.1% | 66.7% | 68.2% (XGBoost) |
| **WESAD** | 三分类 | 72.4% | 75.1% | 68.9% | 76.3% | 78.5% (SVM) |
| **AMIGOS** | 高/低 Arousal | 60.1% | 62.5% | 57.8% | 63.2% | 64.8% (RF) |

**关键观察**：
- **Subject-independent 准确率通常仅有 55-75%**
- Arousal 分类比 Valence 分类容易（因为 Arousal 与 SNS/PNS 更直接关）
- 三分类任务更难，准确率通常下降 5-10%

**与 Subject-Dependent 的对比**：
- 如果在同一个被试者的数据上做交叉验证（Subject-Dependent），准确率可达 **80-95%**
- 这意味着最大的挑战不是"情绪和 HRV 的关联强不强"，而是"不同人的 HRV 基线差异太大"

### 1.6 深度学习方法与准确率

**方法一：1D-CNN on Raw ECG/PPG**

```python
# 典型架构 (PyTorch 风格)
class ECG_CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv1d(1, 64, kernel_size=50, stride=6)
        self.bn1 = nn.BatchNorm1d(64)
        self.pool1 = nn.MaxPool1d(2)
        
        self.conv2 = nn.Conv1d(64, 128, kernel_size=25, stride=3)
        self.bn2 = nn.BatchNorm1d(128)
        self.pool2 = nn.MaxPool1d(2)
        
        self.conv3 = nn.Conv1d(128, 256, kernel_size=10)
        self.bn3 = nn.BatchNorm1d(256)
        self.global_pool = nn.AdaptiveAvgPool1d(1)
        
        self.fc = nn.Sequential(
            nn.Linear(256, 64),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(64, num_classes)
        )
    
    def forward(self, x):
        x = self.pool1(F.relu(self.bn1(self.conv1(x))))
        x = self.pool2(F.relu(self.bn2(self.conv2(x))))
        x = self.global_pool(F.relu(self.bn3(self.conv3(x))))
        x = x.view(x.size(0), -1)
        return self.fc(x)
```

**准确率**：
- DEAP Arousal 二分类（Subject-Independent, LOSO）：**65-72%**
- 优于传统 ML 约 3-5%

**方法二：LSTM/BiLSTM on RR Intervals**

```python
class HRV_LSTM(nn.Module):
    def __init__(self, input_size=1, hidden_size=64, num_layers=2, num_classes=2):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers, 
                           batch_first=True, bidirectional=True)
        self.fc = nn.Linear(hidden_size*2, num_classes)
    
    def forward(self, x):
        # x: (batch, seq_len, 1)
        lstm_out, _ = self.lstm(x)
        # 取最后一个时间步的输出
        out = self.fc(lstm_out[:, -1, :])
        return out
```

**准确率**：
- DEAP Arousal 二分类（LOSO）：**68-75%**
- 利用了时序信息，通常比 CNN 好 2-3%

**方法三：Attention + Transformer**

```python
class HRV_Transformer(nn.Module):
    def __init__(self, d_model=64, nhead=4, num_layers=3):
        super().__init__()
        self.embedding = nn.Linear(1, d_model)
        encoder_layer = nn.TransformerEncoderLayer(d_model, nhead, batch_first=True)
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers)
        self.fc = nn.Linear(d_model, num_classes)
    
    def forward(self, x):
        x = self.embedding(x)  # (batch, seq, d_model)
        x = self.transformer(x)
        x = x.mean(dim=1)  # global average pooling
        return self.fc(x)
```

**准确率**：
- DEAP Arousal 二分类（LOSO）：**70-78%**
- 最新的 TACOformer (arXiv 2024) 在 DEAP 上达到 **81.2%** (Subject-Independent)

**方法四：混合架构 (CNN+LSTM+Attention)**

```
Raw Signal
    ↓ Conv1D layers (local feature extraction)
    ↓ LSTM layers (temporal dynamics)
    ↓ Self-Attention (global dependencies)
    ↓ Dense layers (classification)
```

**准确率**：
- 通常是最高的单模态方法，在 DEAP 上可达 **75-82%**

### 1.7 多模态融合策略

**核心认知**：单独使用 HRV 的准确率上限大约在 75-80%（Subject-Independent）。多模态融合是突破瓶颈的主要方向。

**融合策略**：

| 策略 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **Early Fusion** | 在特征层级拼接多个模态的特征向量 | 简单直接 | 维度骨灼、模态间不匹配 |
| **Late Fusion** | 每个模态独立分类，结果投票 | 灵活、可解释 | 可能丢失模态间交互信息 |
| **Hybrid Fusion** | 中间层级融合 | 平衡两者优点 | 复杂度高 |
| **Attention Fusion** | 使用注意力机制动态权重融合 | 自适应、效果好 | 计算成本高 |

**实际准确率提升**（以 DEAP 为例，Subject-Independent）：

| 模态组合 | Arousal 二分类 | Valence 二分类 |
|---------|--------------|---------------|
| HRV only | 70-75% | 60-65% |
| HRV + EDA | 75-80% | 65-70% |
| HRV + EDA + EEG | 82-88% | 72-78% |
| HRV + EDA + EEG + 面部 | 85-92% | 75-82% |
| HRV + EDA + EEG + 面部 + 语音 | 88-95% | 78-85% |

**关键结论**：
- HRV + EDA 是最具成本效益的组合（两者都可用低成本可穿戴设备获取）
- EEG 的提升明显，但需要头戴设备
- 面部和语音的提升在室内环境明显，在移动场景下降严重

### 1.8 个体差异性问题与解决方案

**问题的根源**：
- 不同人的静息心率可能相差 30-40 BPM
- 不同人的 HRV 基线可能相差 3-5 倍
- 同一个人在不同时间的基线也会波动（睡眠、咖啡、运动、月经周期等）

**解决方案 A：基于被试者的标准化 (Subject-Specific Normalization)**

```python
# 方法 1：Z-score normalization per subject
normalized_rr = (rr_intervals - subject_mean_rr) / subject_std_rr

# 方法 2：使用被试者的基线期 (baseline period)
baseline_mean = np.mean(baseline_rr)  # 实验前的静息状态
normalized_rr = rr_intervals / baseline_mean

# 方法 3：使用个人的最大/最小值进行 Min-Max 归一化
normalized_rr = (rr_intervals - subject_min) / (subject_max - subject_min)
```

**解决方案 B：域适应 (Domain Adaptation)**

```
目标：将源域（已标注数据）的知识迁移到目标域（新用户）

方法：
1. 对抗域适应 (DANN)：训练一个特征提取器，使其无法区分数据来自哪个被试者
2. 对抗性最小化：让不同被试者的特征分布尽量接近
3. 元学习 (Meta-Learning)：学习如何快速适应新用户
```

**解决方案 C：少样本学习 (Few-Shot Learning)**

```
实施：
1. 在大量被试者上预训练一个基础模型
2. 新用户只需要少量标注数据（10-20 分钟）
3. 对基础模型进行微调 (fine-tuning)
```

**解决方案 D：个人化校准周期**

```
实际产品最常用的方法：
1. 用户首次使用时，记录 3-7 天的基线数据
2. 计算个人的平均心率、HRV 范围
3. 后续检测使用个人化阈值
```

**各方案效果对比**（在 DEAP 上）：

| 方法 | Subject-Independent 准确率 | 需要新用户数据 |
|------|------------------------|--------------|
| 无处理 | 62% | 0 |
| Z-score normalization | 65% | 0 |
| Baseline normalization | 68% | 5 分钟基线 |
| Domain Adaptation (DANN) | 72% | 0 |
| Few-Shot (10 样本) | 76% | 10 分钟 |
| Personal Calibration (7天) | 82% | 7 天 |

### 3.3 波峰检测层

**Pan-Tompkins 算法完整实现**：

```python
def pan_tompkins(ecg, fs):
    """
    Pan-Tompkins R-peak detection algorithm
    返回 R 波位置索引
    """
    # 1. 带通滤波
    nyq = 0.5 * fs
    b, a = butter(4, [5/nyq, 15/nyq], btype='band')
    filtered = filtfilt(b, a, ecg)
    
    # 2. 微分
    diff = np.diff(filtered)
    
    # 3. 平方
    squared = diff ** 2
    
    # 4. 移动窗口积分
    window_size = int(0.15 * fs)  # 150ms
    integrated = np.convolve(squared, np.ones(window_size)/window_size, mode='same')
    
    # 5. 阈值检测
    peaks = []
    threshold = 0.5 * np.max(integrated)
    refractory = int(0.2 * fs)  # 200ms 不应期
    
    i = 0
    while i < len(integrated):
        if integrated[i] > threshold:
            # 在搜索窗口内找最大值
            search_end = min(i + refractory, len(integrated))
            peak_idx = i + np.argmax(integrated[i:search_end])
            peaks.append(peak_idx)
            i = search_end
        else:
            i += 1
    
    # 6. 回望搜索：在原始 ECG 中精细定位
    r_peaks = []
    for p in peaks:
        search_start = max(0, p - int(0.1*fs))
        search_end = min(len(ecg), p + int(0.1*fs))
        r_peak = search_start + np.argmax(ecg[search_start:search_end])
        r_peaks.append(r_peak)
    
    return np.array(r_peaks)
```

### 3.4 特征提取层

**完整特征集**：

```python
def extract_hrv_features(rr_intervals, fs=4.0):
    """
    提取完整的 HRV 特征集
    """
    features = {}
    
    # ========== 时域特征 ==========
    features['mean_rr'] = np.mean(rr_intervals)
    features['std_rr'] = np.std(rr_intervals, ddof=1)  # SDNN
    features['rmssd'] = np.sqrt(np.mean(np.diff(rr_intervals)**2))
    features['nn50'] = np.sum(np.abs(np.diff(rr_intervals)) > 50)
    features['pnn50'] = 100.0 * features['nn50'] / len(np.diff(rr_intervals))
    features['nn20'] = np.sum(np.abs(np.diff(rr_intervals)) > 20)
    features['pnn20'] = 100.0 * features['nn20'] / len(np.diff(rr_intervals))
    features['median_rr'] = np.median(rr_intervals)
    features['mad_rr'] = np.median(np.abs(rr_intervals - np.median(rr_intervals)))
    features['range_rr'] = np.max(rr_intervals) - np.min(rr_intervals)
    features['cv_rr'] = features['std_rr'] / features['mean_rr']  # 变异系数
    
    # 高阶矩
    features['skewness'] = scipy.stats.skew(rr_intervals)
    features['kurtosis'] = scipy.stats.kurtosis(rr_intervals)
    
    # ========== 频域特征 ==========
    # 插值为均匀采样
    rr_times = np.cumsum(rr_intervals) / 1000.0
    t_interp = np.arange(rr_times[0], rr_times[-1], 1.0/fs)
    cs = CubicSpline(rr_times, rr_intervals)
    rr_interp = cs(t_interp)
    rr_detrended = rr_interp - np.mean(rr_interp)
    
    # Welch 谱估计
    f, psd = welch(rr_detrended, fs=fs, nperseg=min(256, len(rr_detrended)//4))
    
    features['total_power'] = np.trapz(psd, f)
    features['vlf_power'] = np.trapz(psd[(f>=0.003)&(f<0.04)], f[(f>=0.003)&(f<0.04)])
    features['lf_power'] = np.trapz(psd[(f>=0.04)&(f<0.15)], f[(f>=0.04)&(f<0.15)])
    features['hf_power'] = np.trapz(psd[(f>=0.15)&(f<=0.4)], f[(f>=0.15)&(f<=0.4)])
    features['lf_hf_ratio'] = features['lf_power'] / features['hf_power']
    features['lf_norm'] = features['lf_power'] / (features['lf_power'] + features['hf_power'])
    features['hf_norm'] = features['hf_power'] / (features['lf_power'] + features['hf_power'])
    
    # ========== 非线性特征 ==========
    # Poincaré plot
    rr_n = rr_intervals[:-1]
    rr_n1 = rr_intervals[1:]
    features['sd1'] = np.std(rr_n1 - rr_n) / np.sqrt(2)
    features['sd2'] = np.std(rr_n1 + rr_n) / np.sqrt(2)
    features['sd1_sd2_ratio'] = features['sd1'] / features['sd2']
    
    # 浅度散度 (简化版)
    def sampen(U, m, r):
        def _phi(m):
            N = len(U)
            x = np.array([U[i:i+m] for i in range(N-m+1)])
            C = np.sum(np.max(np.abs(x[:, None] - x[None, :]), axis=2) <= r, axis=1)
            return np.sum(np.log(C / (N-m+1))) / (N-m+1)
        return _phi(m) - _phi(m+1)
    
    try:
        features['sampen'] = sampen(rr_intervals, m=2, r=0.2*np.std(rr_intervals))
    except:
        features['sampen'] = 0
    
    return features
```

### 3.5 情感推断模型层

**实用架构**（适合产品化）：

```python
import torch
import torch.nn as nn

class HRV_EmotionClassifier(nn.Module):
    """
    基于 HRV 特征的情绪分类器
    输入：handcrafted features (batch, num_features)
    输出：valence 和 arousal 的二分类
    """
    def __init__(self, input_dim=25, hidden_dims=[64, 32]):
        super().__init__()
        
        layers = []
        prev_dim = input_dim
        for h in hidden_dims:
            layers.extend([
                nn.Linear(prev_dim, h),
                nn.BatchNorm1d(h),
                nn.ReLU(),
                nn.Dropout(0.3)
            ])
            prev_dim = h
        
        self.feature_extractor = nn.Sequential(*layers)
        
        # 多任务输出
        self.valence_head = nn.Linear(prev_dim, 2)
        self.arousal_head = nn.Linear(prev_dim, 2)
    
    def forward(self, x):
        features = self.feature_extractor(x)
        valence = self.valence_head(features)
        arousal = self.arousal_head(features)
        return valence, arousal

# 损失函数
def emotion_loss(valence_pred, arousal_pred, valence_true, arousal_true):
    ce = nn.CrossEntropyLoss()
    loss_v = ce(valence_pred, valence_true)
    loss_a = ce(arousal_pred, arousal_true)
    return loss_v + loss_a
```

```python
class EmotionSmoother:
    """
    移动平均平滑情绪输出，避免颠沿
    """
    def __init__(self, window_size=10):
        self.window = []
        self.window_size = window_size
    
    def update(self, new_prediction):
        self.window.append(new_prediction)
        if len(self.window) > self.window_size:
            self.window.pop(0)
        return np.mean(self.window, axis=0)
    
    # 或者使用低通滤波
    def lowpass_smooth(self, predictions, alpha=0.3):
        smoothed = [predictions[0]]
        for p in predictions[1:]:
            smoothed.append(alpha * p + (1-alpha) * smoothed[-1])
        return smoothed
```

## 第四部分：核心挑战与技术细节

### 4.1 个体基线差异

**现象**：
- 运动员的静息心率可能是 45 BPM，普通人是 70 BPM
- 同一情绪强度下，不同人的 HRV 变化幅度可能相差 5 倍

**技术对策**：
1. **个人化基线校准**：至少3-7天的静息状态数据
2. **相对化特征**：不用绝对值，而用"相对于基线的变化百分比"
3. **在线学习**：模型持续适应用户的新数据

### 4.2 生理混杂因素

| 因素 | 对 HRV 的影响 | 处理方案 |
|------|------------|---------|
| 运动 | 剧烈下降 | 加速度计检测，运动时屏蔽 |
| 咖啡 | 短期下降 | 记录摄入时间，排除分析窗口 |
| 睡眠不足 | 全面下降 | 夜间 HRV 追踪 |
| 呼吸 | HF 带与呼吸同步 | 控制呼吸频率或使用 HF 之外的指标 |
| 月经周期 | 波动 | 性别特定的基线 |
| 药物 | 因药而异 | 药物日志 |

### 4.3 标注可靠性问题

**问题**：
- 同一人在不同时间对同一视频的情绪打分可能相差 2-3 分
- 外部观察者和自我报告的一致性通常仅 0.4-0.6 (ICC)
- 文化背景影响情绪表达

**影响**：
- 标注噪声大，模型上限受限
- 对"微小情绪变化"的检测能力差

### 4.4 实时性约束

| 阶段 | 延迟要求 | 技术挑战 |
|------|---------|---------|
| 信号采集 | < 1s | 传感器响应时间 |
| 预处理 | < 100ms | 滤波器群延延 |
| 波峰检测 | < 50ms | 窗口大小与延迟的权衡 |
| 特征计算 | < 50ms | 频域分析计算量 |
| 模型推理 | < 10ms | 端侧模型优化 |
| **总延迟** | **< 1-2s** | 实时反馈要求 |

### 4.5 跨设备泛化

**问题**：
- Apple Watch 的 PPG 和 Garmin 的 PPG 是不同的传感器
- 采样率不同，滤波器不同
- 算法隐藏在厂商 SDK 后面

**对策**：
- 使用原始 RR 间期（而不是工厂计算的 HRV）作为输入
- 在多种设备上采集数据训练
- 设备特征适配 (Domain Adaptation)

### 5.1 完整情感识别 Pipeline

```python
import numpy as np
import scipy.signal
import scipy.stats
from scipy.interpolate import CubicSpline
from scipy.signal import welch, butter, filtfilt
import torch
import torch.nn as nn
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import LeaveOneGroupOut

class HRV_EmotionPipeline:
    def __init__(self, fs=512, window_seconds=60, overlap=0.5):
        self.fs = fs
        self.window_size = int(window_seconds * fs)
        self.step_size = int(self.window_size * (1 - overlap))
    
    def bandpass_filter(self, signal, lowcut=0.5, highcut=40.0):
        nyq = 0.5 * self.fs
        low, high = lowcut/nyq, highcut/nyq
        b, a = butter(4, [low, high], btype='band')
        return filtfilt(b, a, signal)
    
    def detect_peaks(self, signal):
        """简化的动态阈值波峰检测"""
        # 使用 Pan-Tompkins 或简单方法
        diff = np.diff(signal)
        squared = diff ** 2
        window = int(0.1 * self.fs)
        integrated = np.convolve(squared, np.ones(window)/window, mode='same')
        
        threshold = 0.3 * np.max(integrated)
        peaks, _ = scipy.signal.find_peaks(integrated, 
                                            distance=int(0.3*self.fs),
                                            prominence=threshold*0.5)
        return peaks
    
    def compute_rr_intervals(self, peaks):
        rr = np.diff(peaks) / self.fs * 1000  # 转为 ms
        # 过滤异常值
        rr = rr[(rr > 300) & (rr < 2000)]
        return rr
    
    def extract_features(self, rr_intervals):
        if len(rr_intervals) < 10:
            return None
        
        features = {}
        features['mean_rr'] = np.mean(rr_intervals)
        features['sdnn'] = np.std(rr_intervals, ddof=1)
        features['rmssd'] = np.sqrt(np.mean(np.diff(rr_intervals)**2))
        features['pnn50'] = 100.0 * np.sum(np.abs(np.diff(rr_intervals)) > 50) / max(1, len(np.diff(rr_intervals)))
        features['cv'] = features['sdnn'] / features['mean_rr']
        features['skew'] = scipy.stats.skew(rr_intervals)
        features['kurt'] = scipy.stats.kurtosis(rr_intervals)
        
        # 频域
        if len(rr_intervals) > 20:
            rr_times = np.cumsum(rr_intervals) / 1000.0
            t_interp = np.arange(rr_times[0], rr_times[-1], 1/4.0)
            if len(t_interp) > 10:
                cs = CubicSpline(rr_times, rr_intervals)
                rr_i = cs(t_interp)
                f, psd = welch(rr_i - np.mean(rr_i), fs=4.0, nperseg=min(256, len(rr_i)//4))
                features['lf'] = np.trapz(psd[(f>=0.04)&(f<0.15)], f[(f>=0.04)&(f<0.15)]) if np.any((f>=0.04)&(f<0.15)) else 0
                features['hf'] = np.trapz(psd[(f>=0.15)&(f<=0.4)], f[(f>=0.15)&(f<=0.4)]) if np.any((f>=0.15)&(f<=0.4)) else 0
                features['lf_hf'] = features['lf'] / features['hf'] if features['hf'] > 0 else 0
        
        # 非线性
        if len(rr_intervals) > 2:
            features['sd1'] = np.std(np.diff(rr_intervals)) / np.sqrt(2)
            rr_n = rr_intervals[:-1]
            rr_n1 = rr_intervals[1:]
            features['sd2'] = np.std(rr_n1 + rr_n) / np.sqrt(2)
        
        return features
    
    def process_window(self, ecg_window):
        filtered = self.bandpass_filter(ecg_window)
        peaks = self.detect_peaks(filtered)
        rr = self.compute_rr_intervals(peaks)
        return self.extract_features(rr)
```

```python
    for i in range(100):

        yield [data]

converter.representative_dataset = representative_dataset

    f.write(tflite_model)

# 端侧推理示例
interpreter = tf.lite.Interpreter(model_path='hrv_emotion_model.tflite')
interpreter.allocate_tensors()

input_details = interpreter.get_input_details()
output_details = interpreter.get_output_details()

# 实时推理循环
while True:
    features = get_realtime_hrv_features()  # 从传感器获取
    input_data = np.array([features], dtype=np.float32)
    
    # 量化
    scale = input_details[0]['quantization'][0]
    zero_point = input_details[0]['quantization'][1]
    input_data = np.clip(np.round(input_data / scale + zero_point), -128, 127).astype(np.int8)
    
    interpreter.set_tensor(input_details[0]['index'], input_data)
    interpreter.invoke()
    
    output_data = interpreter.get_tensor(output_details[0]['index'])
    # 反量化
    output_scale = output_details[0]['quantization'][0]
    output_zero = output_details[0]['quantization'][1]
    probs = (output_data.astype(np.float32) - output_zero) * output_scale
    
    emotion = np.argmax(probs)
    confidence = probs[0][emotion]
    
    if confidence > 0.7:
```

## 第七部分：未来方向

### 7.1 技术趋势

1. **Foundation Models for Physiological Signals**
   - 大规模预训练模型（类似 BERT 但用于生理信号）
   - 少样本适应新用户

2. **Self-Supervised Learning**
   - 利用未标注数据预训练
   - 对比学习（Contrastive Learning）

3. **Neural Architecture Search (NAS)**
   - 自动发现最优端侧架构

4. **Federated Learning**
   - 在保护隐私的前提下训练全局模型
   - 解决跨用户差异性

### 7.2 产品化趋势

1. **无感知**：rPPG 和远距生理信号检测
2. **多模态可穿戴**：耳机式设备同时获取 ECG + EEG + PPG
3. **情绪 Agent**：将情绪检测与 LLM 结合，提供情感交互

### 7.3 未解决的核心问题

1. **Causality vs Correlation**：HRV 和情绪相关，但不一定因果
2. **Ground Truth**：没有客观的"情绪金标准"
3. **Ecological Validity**：实验室结果是否能延伸到真实世界

---

> 报告结语
> 
> HRV 情感计算是一个"技术可行但产品困难"的领域。科研上，我们已经能够在控制环境下以 70-80% 的准确率检测催化状态；
> 产品上，个体差异性、标注噪声和监管缺位使得"情绪诊断"仍然遥不可及。
> 
> 最有价值的突破方向不是"提高准确率到 99%"，
> 而是"在特定场景下做有用的事"——如压力预警、疲劳检测、睡眠质量评估。
> 
> 这些任务不需要"读懂你的每一种情绪"，
> 只需要"检测你的身体是否处于应激状态"。
